OpenWeatherMap API Key

To fetch live weather data, enter your free OpenWeatherMap API key below. You can also specify it in script.js under API_KEY.

How to get a free API key:

  1. Go to openweathermap.org and sign up for free.
  2. Go to your profile → API keys.
  3. Copy your key and paste it here or into script.js.
